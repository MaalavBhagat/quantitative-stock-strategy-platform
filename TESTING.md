# TESTING.md — how the code is tested

## How to run
```bash
uv run pytest -q                          # all tests (≈ 18 s; 454 tests on 2026-10-28)
uv run --group dashboard pytest -q        # same, with the dashboard packages present (dashboard tests need them)
uv run ruff check . && uv run ruff format --check .
uv run --group dashboard python scripts/smoke_dashboard.py     # every dashboard page loads, banner shown, no bare IDs
uv run --all-groups python scripts/reproduce_reports.py        # every generated report rebuilt and compared with git
uv run python scripts/scan_secrets.py                          # whole git history: no secrets, no licensed data
```
No test uses the internet: HTTP is mocked (`httpx.MockTransport`). Tests that need the git-ignored `data/` folder skip
themselves with the reason printed (`-rs` shows it); on a fresh clone 22 tests skip and the rest pass.

## Mutation checks (a rule broken on purpose → tests must fail → code restored)
| Rule broken on purpose | Result |
|---|---|
| fill at day T's close instead of T+1's open | 9 tests fail (incl. the look-ahead harness) |
| pay-side rounding broken / market value rounded up / unrealised P&L sign flipped | 5 / 3 / 4 tests fail |
| withholding rounded down / a split changing the cost basis | 5 / 4 tests fail |
| S1 sells at the same close / S2 peak = sale price / no split adjustment | 9 / 2 / 2 fail |
| provider-adjusted closes in indicators / z-score window reaching T+1 / "SMA rising" dropped | 1 / 9 / 2 fail |
| SEC fact usable on its filing day ("filed <= T") / returns without the split ratio / as-of "filed <= D" | 2 / 3 / 1 fail |
| 8-K accepted at exactly 16:00:00 counted at that close | 1 fails |
| E1 uses the filing date / C1 reads the next day's SPY / C2 ignores SPY | 3 / 5 / 1 fail |
| registry loads the 2020 event files for every config (Phase 10 fix reverted) | 1 replay fails |
| dashboard verdict table shown raw / strategy menu without names | smoke check FAIL (5 / 24 bare IDs) |
Details and real output: PROJECT_STATUS.md "TESTS RUN" entries.

## What is NOT tested (known gaps)
- Live downloads against the real Tiingo / SEC / RBA / Yahoo servers (only mocked; real runs are checked by the data
  reports instead).
- The dashboard in a real browser (only headless AppTest; screenshots are taken by `scripts/dashboard_screenshots.py`).
- The Phase 4–5 development reports (`reports/runs/`, `reports/experiments/s1_s2_dev…`, `s3_s4_dev…`) are not
  regenerated by `reproduce_reports.py`: their scripts re-run the backtests (explained in that script).
- No type checker (D9); no property-based or load testing; performance is measured, not tested (PROJECT_GUIDE §2).
- Real broker behaviour (Stake fills, real spreads, fractional-share precision) is an assumption, not tested
  (DATA_SOURCES §8).
