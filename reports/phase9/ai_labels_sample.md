# AI labelling side test — 40 SEC 8-Ks read by Claude Code vs the official item codes (Phase 9, Part D)

> **EXPLORATORY — never part of any verdict; no trading use.** AI labels are interpretations, the item codes are
> the filer's own (verified) facts. Generated by `scripts/ai_label_sample.py compare`.

- Model: Claude Opus 5.5 (claude-opus-5-5), running in Claude Code · labelled 2026-10-28 · by Claude Code, from the masked texts printed by `scripts/ai_label_sample.py show`
- Sample: 40 Form 8-K filings 2010–2020 from AAPL, MSFT, KO, PG, XOM, INTC, T — random, seed 20261028
  (`random.Random(seed).sample` over all 8-Ks sorted by accession). Primary document only (no exhibits).
- Masking before labelling: every 'Item N.NN' code and every official item title → [HIDDEN]. Official codes
  were only read by `compare`, after the labels file was saved.
- Exact instruction used: “Read the text of this SEC Form 8-K primary document (item numbers and official item titles have been replaced by [HIDDEN]). Decide which of these categories the filing reports — one or more: bankruptcy; deal completed; deal signed; delisting notice; disclosure / other; earnings; exhibits only; impairment; leadership change; other; restatement / non-reliance; shareholder vote. Use 'other' for a reportable event that fits none of the named categories, and 'exhibits only' only if the filing does nothing but furnish exhibits. Judge from what the text says happened, not from guesses about the company. Give the categories and one short reason.”

## Result

- **Exact agreement** (same set of categories): **37/40 = 92%**
- **At least one category in common**: 40/40 = 100%
- Official categories use the same map as Phase 9 (news/events.py; official items without a named category
  → 'other').
